====================================================================
 Gold 0DTE Put/Call  ->  TradingView   (คู่มือติดตั้งบนมือถือ Android)
====================================================================

โปรแกรมนี้ดึงข้อมูล Put/Call ของ Gold (series ที่ใกล้หมดอายุสุด)
แล้ว copy เข้า clipboard ของมือถือ เพื่อไป paste ในช่อง "Paste P/C Data"
ของ indicator ใน TradingView (format เดียวกับ widget บน Mac)

แหล่งข้อมูล (อัปเดต ก.ย. 2026 — CME ถอดข้อมูล Intraday ออกจาก Vol2Vol
ตัวเก่าที่ดึงจาก Vol2Vol อย่างเดียวจึงใช้ไม่ได้แล้ว):
  - Intraday / OI รายสไตรค์ + ราคา Future : Barchart
      Intraday นับเฉพาะ volume ของ session วันนี้ (เปิด 05:00 ไทย / หน้าหนาว 06:00)
  - IV ที่ใช้คิด SD      : CME QuikStrike Event Volatility (ช่อง vol ของ 0DTE)
  - เส้น Volatility smile : CME Vol2Vol แท็บ Open Interest (Vol Settle)
  - Vol Chg              : CME Settlement Sheet (CME เปิดให้ดูหลัง 12:00 ไทย)
  ส่วนของ CME เป็นตัวเสริม ถ้าดึงไม่ได้ยังได้ข้อมูล Put/Call จาก Barchart เสมอ
  clip ส่งเฉพาะสไตรค์ในช่วง F ± 4σ ให้ความยาวไม่เกินที่ช่องของ TradingView รับได้

ต้องใช้ 2 ไฟล์:
  - setup_cme_termux.sh   (ตัวติดตั้ง มี app ฝังอยู่ในตัว)
ไม่ต้องมีไฟล์อื่น ไม่ต้อง login CME ไม่ต้องมีคอมพิวเตอร์


--------------------------------------------------------------------
 ขั้นที่ 1 : ลงแอป Termux
--------------------------------------------------------------------

ลง "Termux" จาก Google Play Store  (เวอร์ชันปี 2026 ใช้ได้ ทดสอบแล้ว)

หมายเหตุ:
  - เวอร์ชัน Play Store มี "ตัวแอป" Termux:API และ widget รวมมาในตัวแล้ว
    ไม่ต้องลงแอป Termux:API หรือ Termux:Widget แยก
  - แต่ "ชุดคำสั่ง" termux-api (ที่มี termux-clipboard-set) ยังต้องติดตั้ง
    ด้วย  pkg install termux-api  เสมอ ไม่ว่าจะมาจากแหล่งไหน
    -> ตัว setup script รันคำสั่งนี้ให้แล้วในขั้น [1/4] ไม่ต้องพิมพ์เอง
  - ถ้าจะใช้ชุด F-Droid/GitHub แทน ต้องลงแอป Termux + Termux:API
    จากแหล่งเดียวกันทั้งคู่ (ลายเซ็นต้องตรงกัน)


--------------------------------------------------------------------
 ขั้นที่ 2 : ก๊อปไฟล์ setup เข้ามือถือ
--------------------------------------------------------------------

เอาไฟล์  setup_cme_termux.sh  ใส่ไว้ในโฟลเดอร์ Download ของมือถือ
(ส่งผ่าน LINE/Telegram หาตัวเอง, Google Drive, หรือสาย USB ก็ได้)


--------------------------------------------------------------------
 ขั้นที่ 3 : รันตัวติดตั้ง (ทำครั้งเดียว)
--------------------------------------------------------------------

เปิดแอป Termux แล้วพิมพ์ทีละบรรทัด:

    termux-setup-storage
        -> กด "อนุญาต / Allow" ที่เด้งขึ้นมา (ให้ Termux อ่านไฟล์ได้)

    bash /storage/downloads/setup_cme_termux.sh
        -> ถ้าวางไฟล์ไว้ที่อื่น เปลี่ยน path ให้ตรง
        -> (บางเครื่องใช้ /sdcard/Download/ แทน)

ตัวติดตั้งจะ:
    [1/4] ลง python + termux-api
    [2/4] ลง requests
    [3/4] ติดตั้งตัวโปรแกรม + สร้างปุ่ม CME-Gold + alias "cme"
    [4/4] ทดลองดึงข้อมูลจริง 1 รอบ

ถ้าเห็นข้อความประมาณนี้ = สำเร็จ:
    Gold IG2U26 (OG2U6)  exp 2026-09-11  DTE 0.61
    Future 4324.4 (GCV26)   IV 44.99 [event]
    VolSettle 44.99   smile: vol2vol
    Intraday P 322 / C 415   OI P 7225 / C 8943
    clip 2514 chars (±4σ)   1SD@0.6DTE ±78.9
    => P/C data copied to clipboard ...

  อ่านค่า:  IG2U26 = รหัสของ Barchart,  (OG2U6) = รหัสของ CME ตัวเดียวกัน
            IV [event] = ได้ event vol จาก CME,  smile: vol2vol = เส้นจาก CME
            ก่อน 12:00 ไทยจะไม่มีตัวเลขในวงเล็บหลัง VolSettle (Vol Chg) — ปกติ


--------------------------------------------------------------------
 ขั้นที่ 4 : วิธีใช้งานประจำวัน
--------------------------------------------------------------------

มี 2 วิธี เลือกอันไหนก็ได้:

วิธี A) ปุ่มบนหน้าจอ (สะดวกสุด)
    1. ไปหน้า home ของ Android -> กดค้างที่พื้นที่ว่าง -> Widgets
    2. หา "Termux" ในรายการ widget -> ลาก "Termux widget" มาวาง
    3. จะเห็นรายชื่อ -> แตะ "CME-Gold"
    -> Termux เด้งขึ้นมารันสั้นๆ แล้ว copy ข้อมูลให้อัตโนมัติ

วิธี B) พิมพ์คำสั่ง
    เปิด Termux แล้วพิมพ์:   cme
    (ต้องปิด-เปิด Termux ใหม่ 1 ครั้งหลังติดตั้ง เพื่อให้ alias ทำงาน)

จากนั้น:
    เปิดแอป TradingView -> เปิด settings ของ indicator
    -> แตะค้างช่อง "Paste P/C Data" -> Paste
    เสร็จ


--------------------------------------------------------------------
 แก้ปัญหาเบื้องต้น
--------------------------------------------------------------------

* แตะปุ่มแล้วขึ้น "termux-clipboard-set failed"
    -> โปรแกรมจะพิมพ์ข้อมูลออกจอให้แทน copy จากจอเองได้
    -> ถ้าอยากให้ copy อัตโนมัติ: pkg install termux-api

* ไม่เห็น "CME-Gold" ในรายการ widget
    -> เช็คว่าไฟล์มีจริง:   ls ~/.shortcuts/
    -> ถ้าไม่มี = setup ยังไม่สำเร็จ ให้รัน bash ...setup... ใหม่
    -> ถ้ามีแต่ widget ไม่ขึ้น: รีบูตเครื่อง 1 ครั้งแล้วเพิ่ม widget ใหม่

* พิมพ์ cme แล้วไม่รู้จักคำสั่ง
    -> ปิด-เปิด Termux ใหม่ หรือพิมพ์เต็ม:
       python ~/cme-gold/cme_gold_termux.py

* ขึ้น ERROR: barchart: ทุก candidate ว่าง ...
    -> ต่อเน็ตแล้วลองใหม่ ถ้ายังไม่หายอาจเป็นเพราะ Barchart ปรับระบบ
       (แจ้งผู้ดูแลให้อัปเดตตัวโปรแกรม)

* บรรทัด "event vol ข้าม" / "vol2vol ข้าม" / "vol chg ข้าม"
    -> ส่วนของ CME ดึงไม่ได้รอบนี้ โปรแกรมยังทำงานต่อได้:
       IV จะคำนวณเองจากราคา bid/ask ของ Barchart และ smile ใช้ค่าสดแทน
       ("vol chg ข้าม" ก่อน 12:00 ไทย เป็นเรื่องปกติ CME ยังไม่เปิดให้ดู)

* บรรทัด "QuikStrike พักอยู่ถึง ..."
    -> ตัวเบรกทำงาน: CME ตอบแบบที่ดูเหมือนกำลังบล็อก (403/429/หน้า login/หน้าตรวจบอท)
       โปรแกรมเลยหยุดยิง CME ไว้ 12 ชม. (ถ้าเป็นหน้า error ของเขาเอง 2 ชม.)
       กันไม่ให้โดนหนักขึ้น ระหว่างนี้ยังได้ clip ครบ ค่า vol ใช้ของที่เก็บไว้
    -> ถ้ามั่นใจว่าไม่ได้โดนบล็อกและอยากลองทันที:  rm ~/cme-gold/qs_state.json

* ทำไมกดครั้งที่สองเร็วกว่า
    -> ค่า Vol Settle / Vol Chg ไม่เปลี่ยนทั้งวัน โปรแกรมเก็บไว้ในเครื่อง (~/cme-gold/qs_state.json)
       ดึงใหม่ทุก 4 ชม. หรือเมื่อ series เปลี่ยน ยิง CME น้อยลงมาก ลดโอกาสโดนบล็อก

* ตัวเลข Intraday ตอนเช้ามืดน้อยมาก
    -> ปกติ: นับเฉพาะ volume ของ session วันนี้ (เริ่มนับใหม่ 05:00 ไทย)
       เหมือนหน้า Intraday ของ CME เดิม
